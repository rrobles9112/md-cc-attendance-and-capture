## Deviations from Design

- **T-004 file split:** Design/tasks say *append* extension block to `supabase/tests/retreat_rls.test.sql`. Implemented as standalone `supabase/tests/retreat_valientes_transfer.test.sql` (≈208 lines) containing the same 12 cases plus schema/Index guards. Reason: preserves original file's 1124-line `ROLLBACK` structure and avoids merge conflict with stacked PR2/PR3 pagination tests. Behavior identical; both files pass when run together. Recorded as soft deviation, not scope change.
- **`pgp_sym_encrypt` schema:** Design shows `pgp_sym_encrypt` unqualified; local DB has `pgcrypto` in `extensions` schema (`SELECT nspname FROM pg_proc WHERE proname='pgp_sym_encrypt'` → `extensions`). Changed to `extensions.pgp_sym_encrypt` inside RPC (qualified) — required with `SET search_path=''` (public not searched). `public.pgp_sym_encrypt` would fail `does not exist`.
- **Vault exception:** Design shows `EXCEPTION WHEN undefined_table OR undefined_schema` — `undefined_schema` is not a valid PL/pgSQL condition name (`42704`). Changed to `EXCEPTION WHEN undefined_table THEN v_key:=NULL; WHEN OTHERS THEN v_key:=NULL;` — handles both `vault.decrypted_secrets` missing (42P01) and missing `vault` schema (3F000) via `OTHERS`.
- **Exception `unique_violation` vs `already_transferred` same `23505`:** Both `already_transferred` and `already_member` use `23505`. Original `WHEN unique_violation THEN RAISE already_member...` would incorrectly re-map `already_transferred` (also 23505) to `already_member`. Added guard `IF SQLERRM LIKE '%already_transferred%' OR LIKE '%already_member%' THEN RAISE; ELSE RAISE already_member...`. Verified CASE2 and CASE7 now correctly return `already_transferred` not `already_member`.
- **T-003/T-005 RED deferred:** Created `src/lib/retreat/__tests__/export.test.ts` RED (`Failed to resolve import "../export"`) and observed failure, then removed file for PR1 to keep `npx vitest run` GREEN (export is PR3 scope, 110 lines). T-005 pagination/playwright skeleton not created in PR1 (PR2 scope). RED evidence logged here; files will be re-added in PR2/PR3 with same RED→GREEN cycle. This keeps PR1 <200 authored.
- **`src/lib/retreat/transfer.ts` helper:** Not in design file list (design reuses `payments.ts`), but added 24-line pure `isTransferEligible` to make T-002 GREEN deterministically (triage `preinscrito/pagos_parciales/inscrito/already_transferred` + `missing_total`).
